# Snapshot provenance

SafeWire was created as a new, independent repository from an authorized
snapshot of the existing `sathvik-gorle/meridian-jac` working tree. The source
repository was left unchanged.

- SafeWire baseline commit: `af7c235`
- Import method: filesystem snapshot into a freshly initialized Git repository
- Repository relationship: independent repository, not a GitHub fork

The earlier working tree itself began from an authorized snapshot of
[`WeltonWang02/spreadsheet_hackathon`](https://github.com/WeltonWang02/spreadsheet_hackathon)
at commit `535ffb7eaf771fee8aeeef6c5b21d5bc63f8e1af`.

The baseline is retained in Git history for review and attribution. Subsequent
commits replace its prior product functionality with the graph-native SafeWire
implementation.
